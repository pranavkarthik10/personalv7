I wanted to capture a few post ideas that feel natural based on the themes already on this blog: coding agents, LLM behavior, personal workflows, and building things online.

## 1. What Makes a Coding Agent Actually Useful?

A practical post about the gap between demos and day-to-day usefulness:

- orchestration across multiple repos
- better CI/CD feedback loops
- sandbox limits and how they affect real work
- when an IDE agent still beats a cloud agent

## 2. The Best Part of LLMs Is Not the Model, It’s the UX

I’ve already written about model personality, but there’s a bigger post here about the product layer:

- how defaults shape trust
- why verbosity matters
- the tension between helpfulness and conciseness
- what a great assistant experience should feel like

## 3. My Personal Workflow Stack, Explained

I already have a stack page, but a blog post could go deeper into why each tool stays or gets replaced.

Potential angles:

- why I keep coming back to VS Code / Cursor
- how I use Ghostty, Raycast, Obsidian, and Todoist
- what I look for in a browser and why it matters
- the difference between tools I like and tools I rely on

## 4. Building a Personal Website That Actually Feels Like You

This could be a good mix of design and engineering:

- choosing what content belongs on a personal site
- making a site feel maintained instead of abandoned
- balancing aesthetics with readability
- using the site as a living archive of interests

## 5. How I Decide When to Use AI vs Do It Myself

A more opinionated post about judgment calls:

- when AI speeds up the work
- when AI adds noise
- the kinds of tasks I still prefer to do manually
- how I think about correctness versus speed

## 6. Lessons From Writing About Tech While Learning It

A reflective post about documenting your own learning:

- why writing improves clarity
- how public notes turn into future posts
- the value of publishing unfinished thoughts
- how a blog can become a record of your own taste over time

If I had to pick the strongest next post, I’d probably start with the coding agent piece or the LLM UX piece, since those seem to fit the current direction of the blog best.
